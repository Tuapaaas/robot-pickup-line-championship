One robot pickup line for the make.fun Robot Pickup Line Championship: a machine down to its last 2% of battery, spending its final charge on the person in front of it.

> My battery is at 2% and I'm spending my last charge on you — some connections are worth the shutdown.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node --experimental-strip-types main.ts
```
